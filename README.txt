乙級術科每日練習 PWA（原型）
1. 這是網站原始碼，不是公開網址。把整個資料夾部署到 HTTPS 靜態網站主機（如 Netlify 或 GitHub Pages），才可用 Android Chrome 的「加到主畫面／安裝應用程式」。
2. 將來更新網站只要更新主機上的檔案；使用者重新連線可取得新版，不需要重新下載 HTML。
3. 每日隨機時段提醒僅能在 App/網站有開啟且瀏覽器允許運作時觸發。本版本沒有推播伺服器；手機鎖屏或 App 完全關閉時，不能保證通知。真正背景推播需 HTTPS 主機、後端排程、Web Push 訂閱及推播服務。
4. 作答紀錄目前保存在本機 localStorage，不是雲端資料庫；換機不會自動同步。可在設定匯出／匯入 JSON。
5. 本版有 26 題原創術科簡答/計算題，不是官方考題；模考 50 題將重複題，不能據此預測通過正式考試。
6. 2026/10/29 技檢中心公告 116 年 7 月 1 日起報檢者術科方式調整，請以官方最新公告為準。
